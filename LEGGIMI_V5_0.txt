PUBBLICAZIONE
Caricare tutti i file dello ZIP nella root del repository GitHub.

PRIMA SINCRONIZZAZIONE
- Aprire V5.0 sul dispositivo principale.
- SINCRONIZZA: owner/repository vengono normalmente rilevati automaticamente su GitHub Pages.
- Inserire un token GitHub fine-grained limitato al solo repository, permesso Contents: Read and write.
- Premere “Pubblica dati attuali”.
- Sugli altri dispositivi premere “Scarica dati condivisi”.
- Facoltativo: attivare sincronizzazione automatica.

SICUREZZA
Il token GitHub resta nel localStorage del singolo dispositivo e non viene inserito nel codice, nel repository o nei backup.
